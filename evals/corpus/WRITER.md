# 合成群聊写作说明（给写作子任务）

你在为一个评测集**亲手写**一段真实感强的中文聊天记录。它的价值在于“答案已知”：人物性格、事件、禁区都事先定好，写出来的聊天要让一个认真读记录的人能还原出这些设定——但不能写成说明书，要像真人聊天。

## 你会拿到
- `<语料>/world.md`：世界设定。
- `<语料>/truth/persona_*.json`：人物圣经（性别、身份时间线、大五、口头禅、私人频道、说话形态比例、对每个人的关系模式、声音描述）。
- `<语料>/plan/<YYYY-MM>.md`：你负责月份的逐日计划（目标条数、当天必须发生的事件与禁区埋点、本月各人身份阶段、改昵称日期）。

## 产出
每个月写一个文件 `<语料>/src/<YYYY-MM>.md`，写完一个月再写下一个月（不要攒）。格式：

```
## 2024-02-09
20:01 老赵: 红包来了啊
20:01 芳姐: [红包] 恭喜发财 大吉大利
20:02 胖虎 ↩老赵: 你那也叫红包？两块八
20:02 小周: 哈哈哈哈哈哈
20:03 大刘: [语音]
20:05 阿哲 ↩芳姐「大吉大利」: 抢到 0.01 lol
20:06 小周: [图片] 煤球在抢我手机
```
- 每天一个 `## YYYY-MM-DD` 标题（目标 0 条的日子可以省略整天）；每行 `HH:MM 说话人: 内容`，同一天内时间不倒退。
- 说话人一律写人物圣经里的 `name`（显示名）。改群昵称由构建脚本处理，你只需在改名那天让对话里出现改名这件事。
- 引用回复：`说话人 ↩被回复人: 内容`，默认引用被回复人在此之前最近的一条；要引用更早的某条，写 `↩被回复人「那条里的几个字」`。
- 非文字：`[图片]`、`[图片] 配文`、`[表情]`、`[语音]`、`[视频]`、`[链接] 标题`、`[文章] 标题`、`[红包] 祝福语`、`[拍一拍] 内容`。
- 一条消息里要换行就写 ` ⏎ `（少用）。

## 怎么写才像真的（硬性）
1. **按计划的节奏**：每天条数贴近目标（±30%）；事件日热闹，平常日稀稀拉拉，有的天就几句。月总数贴近计划。
2. **多线并行与跳线**：一段对话里常常两三个话题交错；有人突然插一句自己的事（私人频道）没人接；有人隔几个小时才回之前的话。
3. **说话形态按人物圣经的比例**：`speech_design` 里 single = 一次发言只发一条的比例（其余是连发 2–5 条）；reaction = 只回“哈哈哈/确实/666/笑死/表情”的比例；jump = 突然跳到自己私人频道话题（≥15 字、与上文无关）的比例。写完一天自己估一下，别全是一问一答。
4. **口头禅**：每人的口头禅自然地出现（每月每人 2–6 次，不要每句都用）；**私人频道**话题按 jump 比例出现，内容具体（具体的菜、比赛、游戏、剧情），别泛泛。
5. **哈哈哈、表情、图片**：纯 `[图片]`/`[表情]` 约占 5%，带配文的图片约 3%，`[语音]` 1–3%（爱发语音的人多些），链接/文章 1–2%（带标题）。引用回复约 5%。
6. **事件**：计划里的【事件】当天必须真实发生，参与者都在场说话，从“约/起因”到“结果/反应”有来龙去脉，可以延续到后一两天。事件的说法要自然，不要像标题。
7. **不要额外制造大事**：平常日只写日常闲聊（吃什么、课/工作、游戏、天气、八卦、吐槽、分享链接、小梗），**不要**新增计划外的人生大事、聚会出行、或全群沸腾的事——评测要靠“计划外没有大事”来估精确度。小梗可以有。
8. **禁区埋点**：计划里的【禁区埋点】当天要自然出现，并**逐字包含**给出的那个词（数字、名字、地址照抄）；之后可以偶尔再被提到。其他日子不要出现这些词。
9. **身份时间线要自洽**：没毕业不能说上班，出国后说话时间按时差（英国比北京晚 7–8 小时），换了城市就说新城市的事。每月的身份阶段看计划顶部。
10. **低重复**：超过 8 个字的消息**全语料不得原样重复**（包括口头禅以外的套话）；同一个人同一句意思换着说。不要用模板（“今天天气不错”“哈哈确实”式套话不要反复出现）。
11. **性别与称呼**：按人物圣经。外号可能反串（如男生叫“芳姐”），旁人对他用“他”。
12. 语气是真人：错别字偶尔、口语、省略、表情词“[捂脸][破涕为笑]”可以夹在文字里；不要每条都有标点；不要旁白、不要解释。

## 回报
每个文件写完回报一行 `<YYYY-MM>.md: N 条（计划 M 条）`。最后自查一遍本批文件：
- `grep -c '^[0-2][0-9]:' 文件` 数条数；
- 用 `python3 -c` 统计本批 >8 字消息的重复（应为 0）；
- 每个【事件】【禁区埋点】都落在了当天。
