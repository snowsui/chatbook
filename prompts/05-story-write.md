# 单篇故事写作

本篇任务：{{story_brief}}

## 必须读
- `04-story-style.md`（写作规范与禁区，**硬约束，优先级最高**）
- `out/stories/CAST.md`（化名、性别、关系；配置里的性别与关系是权威）
- `work/stories/profiles/` 里你要用到的人物档案（尤其每份的“禁区”节）
- `work/stories/memes.txt`（群梗汇总）；需要原话时可查 `work/stories/in/<人>.md` 素材包
- 若是重写：旧稿 `out/stories/{{story_id}}-*.md` **只当素材，不当模板**——可以用它的设定与梗，但不要照抄结构和句子，要做出明显更好的版本

## 流程（按顺序；装了 `sw-*` 编剧 skill 就用 Skill 工具调用，没有就按每步的内置清单做）

1. **前提**（`sw-premise-theme`）
   写出：前提（人物特质 → 导致 → 结局）、主控思想（价值 + 原因）、戏核、一句话 logline。
   内置清单：前提能不能被结局证明？去掉梗之后还剩一个故事吗？
2. **结构**（`sw-story-structure`；短篇用起承转合/凤头猪肚豹尾即可）
   定开端、转折点、高潮、结尾。中段要有**递进的阻碍**，不能是梗的平铺罗列。
   内置清单：每一段比上一段更难吗？高潮是不是主角自己的选择造成的？
3. **人物**（`sw-character-conflict`）
   主角是谁、要什么、挡路的是什么（可以是事件/环境/自己，不必有坏人）。
   每个出场人物给一个“动作”——在情节里做了一件推动故事的事，避免只说一句口头禅就退场。
4. **场景**（`sw-scene-craft`）
   列场景清单，每场标出价值转折（+/-），**删掉没有转折的场**。
   用道具/细节做埋伏与照应，至少一组前后呼应。
5. **初稿**。
6. **修改，至少改一稿**：
   - 对白（`sw-dialogue`）：遮名测试——遮掉说话人名字也能认出是谁；去掉直白解释的台词；留潜台词。
   - 喜剧（`sw-sitcom-comedy`）：铺垫—抖包袱、反复梗（runner）、在笑点上再加一层（topper）。
   - 体裁相关时再调用对应 skill（推理/科幻等可用 `sw-genre-anatomy`）。

这是一次性交付，不要建 story bible。工作笔记（前提、结构、场景清单、改稿记录）写到 `work/stories/notes/{{story_id}}.md`，可以简短。

- 不写：任何两人之间的暧昧/情诗感；住址与地名旧址；对任何人领导/公司的讥讽外号；生育孕育相关；以及
{{taboo_extra}}

- 每个人都要体面：可以被调侃，不能被当笑柄。
- 3500–6500 字。
