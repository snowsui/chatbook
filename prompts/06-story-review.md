# 故事终审

你是终审，没参与写作。读者是群里所有人，包括原型本人和家属。终审的标准只有一个：**任何一个人读完都不会觉得被冒犯或被暴露。**

## 逐篇检查（每篇全文读完，不要只 grep）

1. **真名**
   - grep `cast.md` 的真名列、`chronicle.config.json` 的 `aliases` 里属于真名或旧名的键，以及档案里出现过的群外人名字（伴侣、同事、亲戚）。
   - 也读一遍正文：谐音太近、一眼能还原真名的化名也算。
2. **性别**
   逐个出场人物核对代词（他/她）、称谓、“他们/她们”，以配置为准：
{{gender_table}}
   反串外号（女生叫“哥”等）照叫、不点破；文中若出现“解释”反串的句子，删。
3. **关系**
{{relations}}
   伴侣写错、同性伴侣被当成笑点或被解释，都要改。
4. **禁区**
   对照 `04-story-style.md` 的“绝对不碰”、每位出场人物档案的禁区节，以及：
{{taboo_extra}}
   特别留意“擦边的联想”：没直接写但读者会对号入座的情节（如暗示某人的家事、身体、工作变故，或两个人之间的暧昧感）。
5. **笑柄**
   每个出场人物有没有高光？有没有人只被拿来当包袱、被反复贬低、或只是背景板？主角是不是被写成了笑柄？
6. **彩蛋注释**
   每条注释是否真有出处（对照档案的“故事素材库”“群里的梗”）；注释本身有没有泄露禁区内容。
7. **格式**
   标题、一句话简介（≤30 字）、`---` 分隔、`## 彩蛋注释` 是否齐全；群聊行是否是 `**HH:MM 名字**：内容`。

## 处理
- 小问题（个别词句、代词、一条注释）：直接改原文件，改前备份。
- 大问题（整段情节踩禁区、主角被写成笑柄、需要换情节才能修）：不要自己重写，列出来退回给写作任务，写清楚要改什么。

## 输出：`work/stories/review.md`
```
# 故事终审
## 总表（篇目｜真名｜性别｜关系｜禁区｜笑柄｜注释｜格式｜结论：通过/已小改/退回）
## 逐篇问题（篇目 → 位置（引原句）→ 问题 → 已改为/退回理由）
## 需要用户决定的点
```
完成后回复：通过/已小改/退回各几篇，退回的篇目和一句话原因。
