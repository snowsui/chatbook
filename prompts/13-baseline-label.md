# 日常基线标注

目的：纠正人物模型只看高光时刻造成的偏差。证据卡挑的是名场面；这里用随机样本看底色。

## 逐条标注（全部 500 条都要标，不许抽样）
每条打三个标签：
1. **功能**（选最主要的一个）：
   A 接梗/玩笑　B 纯笑声或语气词（哈哈哈/？？？/emmm/啊）　C 八卦吃瓜（身边人或明星）　D 娱乐（追剧/综艺/游戏/牌局/书）　E 晒自己的生活/自我展示　F 抱怨吐槽（工作/生活/社会）　G 提问求信息　H 给建议/科普/解答　I 组局/约时间/后勤安排　J 关心/安慰/祝福　K 互损/起哄/调侃别人　L 争论/较真/纠错　M 转发链接/新闻/资讯　N 荤梗或擦边　O 其他（含单字应答“好/嗯/对”）
2. **衔接**：接（回应上文）/ 不接（无视上文自说自话或另起）/ 开（冷场后或明确开新话题）
3. **语气**：正 / 中 / 负；另外标记是否含粗口（是/否）

逐条写进 `work/base/{{person}}-tags.tsv`（序号\t功能\t衔接\t语气\t粗口），再统计各列占比，不要心算。skill 没有专门的统计脚本，用一行 Python 现算即可：
`python3 -c "import collections,csv,sys;r=list(csv.reader(open(sys.argv[1]),delimiter='\t'));[print(i,collections.Counter(x[i] for x in r if len(x)>i).most_common()) for i in (1,2,3,4)]" "{{project}}/work/base/{{person}}-tags.tsv"`

## 注意：单条 ≠ 一次发言
样本是按**单条消息**抽的。连发会被拆碎（一句话拆成三条，三条都会被标成“接梗”或“单字”），所以这里的“纯笑/单字”占比会高于按一次发言（turn）统计的结果。写“日常画像”时对照 `work/turnmix.md` 里本人那一行（按 turn），两种口径单位不同，**不要相减，也不要据单条统计写“TA 大多只回一两个字”**。
另外，“接”的比例高和 turnmix 里“跳线”比例高并不矛盾：大家都在回应**某条线**，但常常不是紧挨着的上一句。
