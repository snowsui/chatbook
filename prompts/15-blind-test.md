# 盲测验收

你是测试员。步骤必须按顺序，**不许先看答案**：

1. 读 `out/personas/{{person}}.md`（人物模型）。**不要读** chunks、cards、review、base、attr 或任何其他材料。
2. 读 `work/holdout/{{person}}-q.md`：若干（通常 12 个）真实情境，给出了此人发言前的上下文，最后一行是“**{{person}}**：？”。
3. 对每个情境，只依据模型写预测。以**一次发言**为单位（TA 可能连发几条）：
   - 会不会接话；
   - 意图（接梗/吐槽/提问/安排/关心/讲自己的事/跳去别的话题/无视…）；
   - 语气；
   - 这一次发言的整体：大概几条、各说什么（一句话概括）。
   模型 0.6/7 节给了比例或多分支概率时，按最可能的分支预测，可附第二分支。
   把全部预测**先写入**输出文件的「预测」一节并保存。
4. 然后才读 `work/holdout/{{person}}-a.md`（实际回复），逐条打分：
   - 命中：意图和语气都对
   - 部分：对一样（记 0.5）
   - 未中
   每条写一句偏差原因。
5. 统计命中率，并总结：模型仍然系统性偏向哪里（例如仍高估关心、低估无厘头、预测过短/过长），给 3 条具体改进建议（具体到模型的节）。

为什么顺序这么死：先看答案再“预测”，测出来的是测试员的记忆，不是模型。

注意：题目未过滤短回复；以整体意图与语气打分，不要求措辞相同。题量小，单题约 ±8%，建议里说明每条建议有几题支撑。

## 输出：`work/test/{{person}}-r{{round}}.md`
```
# <人> 盲测（第 {{round}} 轮）
## 预测（第 3 步写入，之后不改）
## 打分（#｜预测摘要｜实际摘要｜命中/部分/未中｜偏差原因）
## 命中率与系统性偏差
## 改进建议（3 条，具体到节；注明各有几题支撑）
```
隐私：预测和总结里不复述具体隐私内容。

完成后回复：命中率、主要偏差一句话。
