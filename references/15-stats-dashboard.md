# ⑮ 数据页（群聊统计看板）

目标：一页“只数不读”的统计——谁话最多、几点最热闹、谁最爱接谁的话、谁和谁总在同一段对话里。群友打开会去找自己那张数据卡，也会截图发群。它是零 LLM 成本的模块：只要有 `work/all.json` 就能出。

```
python3 <skill>/scripts/build_stats.py --project <dir>          # → work/stats.json + out/stats.html（单文件，数据内嵌）
python3 <skill>/scripts/build_stats.py --project <dir> --no-page  # 只算数据
python3 <skill>/scripts/package_site.py --project <dir>         # 网站版：第四栏 /stats（数据、脚本、字体抽成带哈希的文件）
python3 <skill>/scripts/privacy_gate.py --project <dir> --target stats   # 单独过闸门
```

前端是 assets/templates/stats.html + stats.js：全部图表 SVG 自绘、无外部依赖，手机宽度无横向滚动；`config.lang = "en"` 时界面文案、数字格式、分词都换成英文。

## 一、开工前要用户拍板的事

一次问清，写进 config（见第四节的键）：

1. **复读句能不能展示原文。** 复用大事记的开关 `pages.show_chat_groups`：只有列在里面的群，复读句才上页面；默认空 = 只算次数。常见情形：一个小圈子里聊私事的群、一个更多人在的闲聊群——私事群的原文不展示，复读句只取闲聊群。
2. **会暴露作息的视图要不要。** 夜猫子榜（0–5 点占比）、早鸟榜、每人活跃时段、数据卡里的“最活跃时段”，等于公开了每个人几点睡几点起；有人在意（倒班、带娃、失眠）。问用户，不要的写进 `stats.hide`（`night` / `early` / `clock`）。
3. **潜水榜要不要。** 默认只在核心成员里排发言最少的几位，见第二节；用户觉得会伤人就 `stats.divers: "off"`。
4. **核心成员是谁。** 缺省 `config.core`（roster.py 圈定的核心人物），没有就 `config.people`（≥3 人时），否则 `members`；也可以直接写 `stats.core`（优先级最高）。核心与否只影响潜水榜和关系图的配色。
5. **口头禅、词云发出去之前给用户过一眼。** 机器滤得掉敏感词，滤不掉“只有本群知道的梗背后是谁的伤心事”。用户要删的词，写进 `sensitive_words`（或 `--add-blocked`），重跑。

## 二、每项统计的口径与为什么

所有统计按“群 × 年份”组合各算一份（只有一个群时不出群筛选）；第一年不足 3 个月时并进下一年（与大事记一致）。按人统计的对象是 `members`（不写时按发言量推断）；成员以外的发言人只计入整体数字——几百人的大群里，路人不上榜、不进矩阵。

- `roster.py apply --drop` 排除的人（机器人、广告号）整个不计：条数、说过话的人数、各榜都不含 TA。
- 没有真实时刻的群（无时间的手动 txt，ingest 记在 `work/ingest.json` 的 `no_time`）不进作息类统计：热力图、每人活跃时段、夜猫子/早鸟（分母只算有真实时刻的消息）、被 @/引用后的回复时延；页面脚注写明是哪些群。
- 口头禅不算接龙行（「1. 某某」）、单字、纯称呼（成员的名字、别名、外号）；分享卡片和年度报告的口头禅用同一口径。

| 视图 | 口径 | 为什么这么定 |
|---|---|---|
| 概览 | 条数、说过话的人数、跨度、有人说话的天数；趋势按日/周/月切换；最热十天 + 当天说得最多的人 | 只看条数，不看字数：拆条发是常态，但概览只是“热不热闹” |
| 星期 × 小时热力图 | 全体消息按星期几 × 小时计数 | — |
| 每人活跃时段 | 24 小时分布，标出峰值小时 | 会暴露作息，可隐藏（`clock`） |
| 消息类型 | all.json 没有类型字段，按 `c` 开头的占位符推断：`[图片]`、`[表情]`、`[语音]`、`[视频]`/`[视频号]`→视频、`[文章]`/`[链接]`/`[音乐]`→链接、`[小程序]`，其余占位符（红包、位置、文件、聊天记录、接龙、拍一拍…）→其他；不以占位符开头的都是文字 | 带配文的图片按图片算（与 turnmix 一致）；txt/csv 导出若没有占位符，图片会被当成文字——这是导出的限制 |
| 龙王 / 每日龙王 / 打卡 / 斗图 | 条数；当天说得最多的次数（并列都算）；最长连续发言天数；表情 + 图片 | 来自真实项目，群友最爱看 |
| 夜猫子 / 早鸟 | `stats.night`（缺省 [0,5) 点）/ `stats.early`（[5,9)）发言占比，≥`board_min_msgs`（200）条才上榜 | 不设门槛，偶尔说一句的人凌晨发一条就是 100%；会暴露作息，要问用户 |
| 深海潜水员 | **只在核心成员里**按发言条数升序取前 `divers_n`（3）位，且最多核心人数的 1/3 | 全员倒序的话，榜上会是本来就只偶尔说话的家属和路人，成了“谁不受欢迎”榜；真实项目改成只在核心成员里点最少的三位。6 个人点 3 个就成了半个群倒序，所以再限 1/3 |
| 复读 | 同一短句（中文 ≤12 字 / 英文 ≤6 词，去掉微信小表情码与空白）被 ≥`repeat_min_people`（2）个不同成员在 `repeat_window_min`（10）分钟内接连发出；中间夹图片/表情不打断，引用回复打断 | 真实项目先用 3 人，复读次数太稀疏、榜单撑不起来；改 2 人后数量够了，但混进了大量“两人各自回答同一个问题”（“好的”“我也是”“不去”）——单拎出来展示既不是梗、又容易断章取义 |
| 最火复读句 | 只取允许展示原文的群；≤`phrase_max`（中文 8 字 / 英文 4 词）；去掉应答句、笑声、敏感句 | 一句话离开上下文就可能被误读（“离婚吧”是玩笑也会被截图），所以宁缺 |
| 口头禅 / 笑法 | 本人的整句文字消息（不含引用回复），≤`phrase_max`，说过 ≥`catch_min_count`（5）次、分布在 ≥`catch_min_months`（3）个月；问句、带 @ 的、接龙的「1.某某」不算；笑声（哈哈/233/笑死、lol/lmao）单列为笑法 | 跨月是为了防“一次性刷屏”：某天为一件事连发 8 遍同一句，不是口头禅 |
| 词云 | 每条消息里出现过的词按“出现在几条消息里”计数（一条里重复不加分），前 100、至少 2 次；中文用 jieba，没装就退化成 2–4 字 n-gram（会出现半截词，建议装 jieba）；英文按单词（≥3 字母）；去掉停用词、人名外号（members/aliases/nicknames/real_names）、带数字字母的中文词、敏感词 | 去人名是因为“某某”永远第一，挤掉真正的群话题 |
| @ 矩阵 | 文本里 `@名字`：按显示名、aliases 的键、nicknames 做最长前缀匹配（英文名还要求词边界，避免 Al 命中 also） | 导出里的 @ 是昵称，昵称会变，所以要 aliases |
| 引用矩阵 | `（回复 X: …）` 里的 X（ingest 已按 aliases 归一） | 只有 json-array / chatlab / telegram 有引用，txt 导出常常没有，矩阵为空就是没有 |
| 接话矩阵 | 同一群里 B 在 A 之后 10 分钟内紧接着发言 | — |
| 回得多快 | 被 @ 或被引用后，TA 在同一群里下一条消息隔多久；12 小时内才算，样本 ≥10 次才出中位数 | 用中位数：一次隔夜回复会把平均数拖得很难看 |
| 冷场救星 | 群里安静 ≥3 小时后第一个开口的人 | — |
| 小团体 | 间隔 >30 分钟切成一段对话；亲密度 = 共现段数 ÷ √(两人各自段数之积)，共现 ≥5 段才算；每人只画最强 3 条边；前端用圆周起点的确定性力导向布局 | 余弦去掉“话多的人跟谁都同框”；不用随机初值，每次打开是同一张图 |
| 数据卡 | 上面各项按人汇总，加“本榜”印章 | — |

**确定性**：所有“集合里的人两两计数”都先排序再数，所有排名并列时按名单顺序 / 字典序打破。真实项目里会话共现用 `set(people)` 迭代、词云用 `Counter.most_common` 取前 N，每次运行 Python 的 hash 种子不同，并列项的顺序就跟着变——关系图、词云、榜单在两次构建之间“自己动了”。`test_stats.sh` 用两个 `PYTHONHASHSEED` 跑同一份数据，要求 stats.json 逐字节相同。

## 三、隐私

页面上只有数字，加上三类短文本：复读句、口头禅/笑法、词云的词（以及人名）。它们要过两层：

1. **构建时直接丢掉**（不进 stats.json）：
   - 内置通用敏感词表：金额（两位以上数字、带单位的金额、钱/工资/房贷…）、健康、孕育（含“接班人”“下一代”这类联想）、住址、外貌、感情、工作变故（含考公/上岸）、公司单位（含常见大厂名）；英文模式有对应的英文表；
   - config 里的 `sensitive_words`、`real_names`、`taboo_extra`（禁区多是一句话，拆成 2–6 字的片段当词用，宁可多滤）；
   - 隐私闸门的全部规则（`privacy_gate.scan_text`：已删除素材、个人信息、内置分层词表——警告也丢）。
2. **构建后过闸门**：`enforce(target='stats')` 扫 stats.json 里所有会上页面的文字 + `config.pages.stats` 文案，默认只提醒、开 `privacy.strict` 才拦（拦下时不出页面；09-privacy.md 第二节）；`package_site` 打包时把 out/stats.html 和其他页面一起再查一遍。

**原文**：复读句只来自 `pages.show_chat_groups` 里的群；口头禅、笑法、词云不受这个开关限制（它们是反复出现的套话和词频，不是某一次对话），但要过上面两层——发布前仍请用户过目。

## 四、配置

```json
{
  "pages": {
    "show_chat_groups": ["B"],
    "tabs": {"stats": "数据"},
    "stats": {"title": "某某群 · 数据", "name": "数据", "seal": "群志", "lede": "可含 <b>", "note": "页脚口径说明（替换默认）",
              "core_label": "老朋友", "other_label": "家属", "divers_note": "老朋友里发言最少"}
  },
  "stats": {
    "core": ["显示名"],
    "repeat_min_people": 2, "repeat_window_min": 10, "phrase_max": 8,
    "catch_min_count": 5, "catch_min_months": 3,
    "night": [0, 5], "early": [5, 9], "board_min_msgs": 200,
    "divers": "core", "divers_n": 3,
    "hide": ["night", "early", "clock", "latency", "divers", "repeat_phrases", "catch", "cloud", "graph"]
  }
}
```

全部可选。`hide` 里列出的视图不出现（数据卡里对应的格子也去掉）；`divers: "off"` 等同于 hide divers。字体复用 `config.fonts`，单文件版按页面实际用字抽子集内嵌。

## 五、产物

- `work/stats.json`：`people[{n, core}]`、`cats`、`years`、`merge`、`groups[{k,label,quote,first,last}]`、`daily`（从第一天起每天的条数，按群）、`combos["群|年"]`（每个组合的概览、热力图、类型、按人统计 `p`、@/引用/接话稀疏矩阵、关系图）、`repeat{events, phrases}`、`catch`、`laugh`、`cloud`、`cfg`、`text`、`noTime`（没有真实时刻的群）。人用 `people` 的下标引用。
- `out/stats.html`：单文件，数据在 `<script type="application/json" id="data">` 里，可以直接发群；放到免费静态托管时可用 build_locked.py 加访问口令。
- 网站版 `site/public/stats.html` + `data/stats.<hash>.json` + `assets/stats.<hash>.js`；Worker 放行 `/stats`。

## 六、已知限制

- txt / csv 导出常常没有图片占位符、引用和 @，类型饼图会几乎全是文字、引用矩阵为空；这是导出格式的上限，页面照常出。
- 词云退化 n-gram 时有半截词（“今天晚”），装 jieba 解决；英文没有词组（“ice cream” 会拆开）。
- “说过话的群友”数的是全部发言人；按人统计只含 members。
- 先生成的单文件页面导航里没有后生成的栏目（要重跑那一页的 build）；网站版打包时会自动补齐。
